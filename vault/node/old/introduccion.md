# Que no es node.js

---

- No es un lenguaje de programacion

- No es una librería

- No es un Framework

- No es una sintaxis de JavaScript

- No es un Servidor

# Que es Node.js?

---

- Los navegadores tienen un motor que interpreta JavaScript

- El más famoso es el V8 desarrollado por Google en C/C++

- En 2009 Ryan Dahl, extrae ese motor y hace que se ejecute de forma externa al navegador

> 💡 Node.js es un intérprete de JavaScript que nos permite ejecutar JavaScript sin necesidad de un navegador

# Como funciona

---

- Cuando instalamos node.js, instalamos el núcleo únicamente

- Para **a**ñadir funcionalidades extra, node.js nos da un gestor de paquetes (NPM y YARN)

- Como recomendación solo usar uno
