# Introducción

---

- Administrador de paquetes estándar para Node.js

- Node Package Manager

## ¿Donde se instalan?

Cuando instala un paquete con npm, puede realizar 2 tipos de instalación:

**Local**

```bash
npm install <package-name>
```

**Global**

```bash
npm install -g <package-name>
```

# npx

---

- Posiblemente se toparán con este comando a futuro (sobre todo si trabajan con React.js)

- Esto ejecuta un paquete de npm sin necesidad de instalarlo de forma global o local.

## Ejemplo

```bash
npx cowsay "Hola mundo"
```
